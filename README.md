# NEXORA — Responsive Learning Resource Interface

A modern, responsive digital learning resource platform designed to help users discover, explore, and learn valuable resources.

## About the Project

NEXORA is a fictional digital learning and knowledge platform created as **Project 1 of the DecodeLabs Internship**.

The project focuses on building a polished, responsive frontend interface using core web development fundamentals without relying on frontend frameworks.

## Features

1. Responsive navigation bar
2. Mobile navigation menu with JavaScript interaction
3. Hero section with clear call-to-action
4. Learning categories section
5. Featured learning resources
6. Responsive resource card grid
7. Call-to-action section
8. Responsive footer
9. Keyboard-visible focus states
10. Mobile, tablet, and desktop responsive layouts

## Technologies Used

1. **HTML5** — Semantic page structure
2. **CSS3** — Styling, Grid, Flexbox, responsive design, and container queries
3. **JavaScript** — Mobile navigation interaction
4. **Google Fonts** — Montserrat and Open Sans

## Responsive Design

NEXORA is designed to work across:

1. Mobile devices
2. Tablets
3. Laptops
4. Desktop screens

The layout adapts using CSS media queries, CSS Grid, Flexbox, and container queries.
